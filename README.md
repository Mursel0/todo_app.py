# To-Do App 📝

A simple command-line task manager built with Python.

## Features
- Add tasks
- Show all tasks with count
- Delete tasks
- Error handling for invalid input
- Warning when task list is empty

## How to Run
1. Install Python
2. Run: python todo_app.py
3. Choose an option: 1, 2, 3 or 4

## Menu
- 1 → Add task
- 2 → Show tasks
- 3 → Delete task
- 4 → Exit

## Topics Used in Code
- Lists
- While loop
- If/elif/else conditions
- User input
- Error handling
